## 1️⃣ GITHUB (Do This First!)

**Why:** GitHub stores your code. Every other platform connects to it.

**Time:** 3 minutes

**Steps:**
1. Go to **https://github.com**
2. Click "Sign up" (big green button)
3. Enter your email
4. Create a password
5. Pick a username (e.g., `petrazim`)
6. Solve the puzzle (prove you're human)
7. Verify your email (click the link they send)
8. **Done!**

## 2️⃣ RENDER (Backend Hosting)

**Why:** Hosts your robot brain (FastAPI backend + database)

**Time:** 2 minutes

**Steps:**
1. Go to **https://render.com**

## 🔑 API KEYS: TEST vs LIVE

You asked: "Do you want test API or live API?"

**Answer: ALWAYS start with TEST (Demo) API keys.**

### Why Test Keys First?

| | Test (Demo) Keys | Live (Real) Keys |
|---|---|---|
| **Money** | Fake money | Real money |
| **Risk** | Zero | You can lose everything |
| **Purpose** | Practice and test | Trade for real profit |
| **When to use** | First 2-4 weeks | Only after you're confident |

### How to Get TEST Keys

**BingX Testnet:**
1. Go to **https://bingx.com**
2. Sign up for an account
3. Go to "Account" → "API Management"
4. Look for "Testnet" or "Demo" option
5. Create API keys
6. **IMPORTANT:** These keys only work on testnet.bingx.com

**TradeLocker Demo:**
1. Go to your TradeLocker dashboard
2. Look for "Demo Account" or "Practice Account"
3. Create API keys for the demo account
4. These keys trade with fake money

**If no testnet is available:**
- Don't add ANY API keys to the system
- The system automatically runs in "Paper Trading" mode
- It receives alerts, calculates trades, but doesn't send real orders
- You see everything on the dashboard, but no real money moves

### When to Switch to LIVE Keys

Only switch to live keys when:
- [ ] You've tested for at least 2 weeks
- [ ] Paper trades are consistently profitable
- [ ] You understand every bot's strategy
- [ ] You've seen 20+ trades execute correctly
- [ ] You understand the risk management rules
- [ ] You're comfortable with the 1% risk per trade rule
- [ ] You have an emergency fund (don't trade rent money)

**My strong recommendation:**
- **Week 1-2:** Paper trading (no API keys)
- **Week 3-4:** Testnet API keys (fake money)
- **Week 5+:** Live API keys (real money, small size)
